# Oncological Applications of Quantum Machine Learning

**Published:** 2023  
**PubMed:** https://pubmed.ncbi.nlm.nih.gov/38105500/  
**Full text:** https://pmc.ncbi.nlm.nih.gov/articles/PMC10729620/

## Purpose
This review surveys QML applications across oncology and is valuable for seeing where breast-cancer work fits into the wider cancer-QML landscape.

## Review scope
The review searched major research databases and included nine studies. Applications discussed include:
- cancer classification
- mammography image processing
- breast-cancer edge/mass detection
- radiotherapy-related decision support
- genomic and clinical applications

Breast cancer represented a substantial portion of the included literature.

## Why it helps
It provides a map of earlier QML-oncology work and exposes how small the evidence base still was at the time.

## Important caution
Some early literature uses strong language about speedups or superiority. Such claims need to be checked against:
- equivalent classical baselines
- data-loading/encoding costs
- actual quantum hardware vs simulation
- dataset size
- external validation
- statistical uncertainty

## Project use
Use this review to build a timeline:
**early proof of concept → hybrid image models → quantum kernels/omics → rigorous external benchmarking → precision-oncology/FTQC research.**

## Evidence level / caution
**Review of early oncology-QML studies; useful context, not clinical proof.**
