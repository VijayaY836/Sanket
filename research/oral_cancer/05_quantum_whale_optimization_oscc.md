# Deep CNN Information Fusion and Improved Whale Optimization Based Smart OSCC Classification Framework Using Histopathological Images

**Authors:** Nasser Alalwan, Mohammad Shabaz  
**Journal:** Expert Systems  
**DOI:** 10.1111/exsy.13536  
**Article:** https://onlinelibrary.wiley.com/doi/10.1111/exsy.13536

## Why it appears in a quantum research search

This work is primarily a **classical deep-learning OSCC classifier**, but it uses an improved optimization approach described as **Quantum Whale Optimization** for feature selection.

That makes it useful as an example of the difference between quantum-inspired optimization and actual quantum computing.

## Architecture

The framework combines features from models including:
- self-attention MobileNetV2
- self-attention DarkNet-19

Features are fused using canonical correlation analysis.

A Quantum Whale Optimization variant is then used to select important features before classification.

## Reported performance

The study reports approximately:
- 98.7% accuracy on one image set
- 96.3% accuracy on another

## Why your team should read it

It demonstrates how the word **quantum** can enter an ML pipeline without a quantum processor.

When writing a literature review, classify this as:

> Quantum-inspired optimization for oral-cancer image classification

rather than:

> Quantum-computer-based oral-cancer detection.

## Evidence classification

**Quantum-inspired optimization, not direct evidence of quantum-computing advantage.**
